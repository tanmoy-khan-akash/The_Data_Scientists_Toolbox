Real-time detection frameworks

In some applications, the detection model we've implemented before is not sufficient. For these applications—where real-time perception is important in order to be able to actuate as quickly as possible—we need a model that is able to detect objects in near real time. The most popular real-time detection frameworks are faster-RCNN, YOLO (You Only Look Once), and SSD (Single-Shot Multibox Detector). Faster-RCNN has shown higher accuracy in benchmarks, but YOLO is able to infer predictions more quickly.
