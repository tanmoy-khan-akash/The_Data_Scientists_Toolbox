Introduction

The focus of this chapter is on applications of deep learning in computer vision. Deep learning, especially Convolutional Neural Networks (CNNs), has revolutionized the field of computer vision. Most benchmarks were beaten by the introduction of deeper CNNs, and some surpassed human-level accuracy for the first time. In this chapter, we will show different kinds of applications within computer vision. Next to CNNs, we will also be using recurrent neural networks (RNNs) in some of these recipes.
