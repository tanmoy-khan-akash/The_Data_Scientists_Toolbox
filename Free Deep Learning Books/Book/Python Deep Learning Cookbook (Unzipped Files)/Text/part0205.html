How to do it...

  1. We start by importing all libraries, as follows:
import numpy as np
import matplotlib.pyplot as plt

from keras.models import Model
from keras.applications.vgg16 import VGG16
from keras.layers import Dense, GlobalAveragePooling2D
from keras.optimizers import Adam

from keras.applications import imagenet_utils
from keras.utils import np_utils
from keras.callbacks import EarlyStopping
  1. In this recipe, we will be using Keras' cifar10 dataset:
from keras.datasets import cifar10
(X_train, y_train), (X_test, y_test) = cifar10.load_data()
  1. We need to preprocess the data before we feed it to our model:
n_classes = len(np.unique(y_train))
y_train = np_utils.to_categorical(y_train, n_classes)
y_test = np_utils.to_categorical(y_test, n_classes)

X_train = X_train.astype('float32')/255.
X_test = X_test.astype('float32')/255.
  1. We will be using the VGG16 model and load the weights without the top dense layers:
vgg_model = VGG16(weights='imagenet', include_top=False)
  1. The great thing about Keras is that when you use the weights for the first time, the weights will be downloaded automatically. This can be seen as follows:

Figure 14.2: Keras automatically downloads the weights
  1. On top of this VGG16 model, we will add a dense layer and an output layer:
x = vgg_model.output
 x = GlobalAveragePooling2D()(x)
 x = Dense(512, activation='relu')(x)
 out = Dense(10, activation='softmax')(x)
  1. We combine the two models as follows:
model = Model(inputs=vgg_model.input, outputs=out)
  1. We can freeze the weights of our VGG16 model with the following code:
for layer in vgg_model.layers:
 layer.trainable = False
  1. Next, we compile our model with the Adam optimizer and output a summary of our model:
opt = Adam()
model.compile(optimizer=opt, loss='categorical_crossentropy', metrics=['accuracy'])
model.summary()
  1. As you can see in the summary, in total our model has over 15 million parameters. However, by freezing the VGG16 layers, we end up with 535,562 trainable parameters.

  2. We define a callback with early stopping to prevent overfitting:

callbacks = [EarlyStopping(monitor='val_acc', patience=5, verbose=0)]
  1. We are now ready to train our model:
n_epochs = 50
batch_size = 512
history = model.fit(X_train, y_train, epochs=n_epochs, batch_size=batch_size, validation_split=0.2, verbose=1, callbacks=callbacks)
  1. Let's plot the training and validation accuracy:
plt.plot(np.arange(len(history.history['acc'])), history.history['acc'], label='training')
plt.plot(np.arange(len(history.history['val_acc'])), history.history['val_acc'], label='validation')
 plt.title('Accuracy')
 plt.xlabel('batches')
 plt.ylabel('accuracy ')
 plt.legend(loc=0)
 plt.show()
  1. In the following figure, we can see that our model tops at a final validation accuracy of around 60%:
