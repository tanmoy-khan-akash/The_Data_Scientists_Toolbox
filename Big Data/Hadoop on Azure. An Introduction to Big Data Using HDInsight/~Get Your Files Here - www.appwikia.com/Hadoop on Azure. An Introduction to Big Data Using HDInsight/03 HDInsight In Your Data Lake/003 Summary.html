• The Azure data lake is composed of three major components. They are. HDInsight, Azure Data Lake, Azure Data Lake Analytics.
  • The Data Lake analytics service is a new distributed analytics service built on Apache YARN.
  • The analytics service can handle jobs of any scale instantly by simply setting the dial for how much power you need.
  • The analytics service also includes U-SQL, a language that unifies the benefits of SQL with the expressive power of user code
  • The Azure Data Lake offers fully managed and supported 100% Apache Hadoop,
  • The Data Lake store provides a single repository where you can capture data of any size type and speed simply without forcing changes to your application as the data scales.
  • Azure Data Factory is a fully managed service that does information production by orchestrating data with processing services as managed data pipelines.
