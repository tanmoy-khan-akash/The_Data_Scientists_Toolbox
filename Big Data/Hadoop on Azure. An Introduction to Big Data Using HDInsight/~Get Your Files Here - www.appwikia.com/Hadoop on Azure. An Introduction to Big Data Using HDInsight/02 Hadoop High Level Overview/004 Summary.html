• Hadoop - A tool that can store and analyze massive amounts of data.
  • HDFS is designed to amass gigantic amount of data and to transfer that data among nodes.
  • The key components of HDFS are NameNode, DataNodes and Secondary NameNode.
  • MapReduce is the engine behind the analysis.
  • The key components of MapReduce are JobTracker, TaskTrackers and JobHistoryServer.
  • Pig is another component of Hadoop and is used to evaluate large data sets made up of high-level language.
  • The basic attribute of Pig programs is ‘parallelization’ which helps Hadoop manage large data sets.
  • Hive is Hadoop’s data warehouse system.
