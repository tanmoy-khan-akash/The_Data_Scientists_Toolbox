Key Terms

Big Data - An approach to storing and analyzing vast amounts of data. The data can be structured or unstructured.

Structured Data - The data inside a table in a database. Only a small percentage of the vast amount of data the world is accumulating.

Unstructured Data - A twitter feed. Text files on a drive. Most of the worlds data is unstructured.

Azure - Microsoft's cloud.

HDInsight - Azure HDInsight is an Apache Hadoop distribution powered by the cloud.

Hortonworks - An organization that packages Hadoop.

Zettabyte - One zettabyte is approximately equal to a thousand exabytes or a billion terabytes.

Hadoop Cluster - A small Hadoop cluster includes a single master and multiple worker nodes.
